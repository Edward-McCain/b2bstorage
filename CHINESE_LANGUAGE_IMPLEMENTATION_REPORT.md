## 🔧 Логика работы

### Приоритет языков:
1. **Выбранный язык пользователя** (`language` из таблицы `users`)
2. **Fallback на русский** (`name_ru`) если перевод отсутствует
3. **Базовое название** (`name`) если нет русского

### Поддерживаемые языки:
- `ru` - Русский (по умолчанию)
- `en` - Английский
- `uz` - Узбекский
- `china` - Китайский (новый)

### Примеры переводов:
```json
{
  "name": "Автомобили и аксессуары",
  "name_ru": "Автомобили и аксессуары",
  "name_en": "Cars and Accessories",
  "name_uz": "Avtomobillar va aksessuarlar",
  "name_china": "汽车和配件"
}
```
