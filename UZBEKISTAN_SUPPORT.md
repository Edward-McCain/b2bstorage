# 🌍 Поддержка пользователей из Узбекистана

## Проблема
Коллеги из Узбекистана не могут зарегистрироваться на сайте, хотя у вас все работает.

## Возможные причины и решения

### 1. Сетевые проблемы
**Проблема:** Медленное или нестабильное интернет-соединение
**Решение:** 
- Увеличены таймауты для медленных соединений
- Добавлена поддержка keepalive соединений
- Улучшена обработка прерванных запросов

### 2. CORS ограничения
**Проблема:** Браузер блокирует запросы из-за CORS политик
**Решение:**
- Улучшена CORS конфигурация
- Добавлена поддержка credentials
- Расширены разрешенные заголовки

### 3. Rate Limiting
**Проблема:** Слишком строгие ограничения на количество запросов
**Решение:**
- Увеличены лимиты для API (120 запросов в минуту)
- Смягчены ограничения для аутентификации (30 запросов в минуту)
- Отдельные лимиты для регистрации (10 попыток в час)

### 4. SSL/TLS проблемы
**Проблема:** Несовместимость с некоторыми SSL шифрами
**Решение:**
- Добавлены дополнительные SSL шифры
- Улучшена поддержка TLS 1.2 и 1.3
- Добавлены современные криптографические алгоритмы

## Примененные улучшения

### Backend (Laravel)
1. **CORS конфигурация** (`config/cors.php`):
   - Добавлены разрешенные паттерны доменов
   - Расширены разрешенные заголовки
   - Включена поддержка credentials
   - Увеличен max_age до 24 часов

2. **Rate Limiting** (`app/Providers/RouteServiceProvider.php`):
   - API: 120 запросов в минуту
   - Аутентификация: 30 запросов в минуту
   - Регистрация: 10 попыток в час

3. **Middleware** (`app/Http/Middleware/InternationalSupport.php`):
   - Логирование запросов из Узбекистана
   - Добавление специальных заголовков
   - Увеличенные таймауты

### Frontend (Nginx)
1. **SSL/TLS**:
   - Добавлены дополнительные шифры
   - Улучшена поддержка современных протоколов
   - Настроены SSL сессии

2. **CORS заголовки**:
   - Расширены разрешенные заголовки
   - Добавлена поддержка credentials
   - Улучшена обработка OPTIONS запросов

3. **Производительность**:
   - Gzip сжатие
   - Увеличенные таймауты
   - Keepalive соединения

## Рекомендации для пользователей из Узбекистана

### 1. Браузер
- Используйте последние версии Chrome, Firefox или Safari
- Очистите кэш и cookies
- Отключите VPN, если используете

### 2. Интернет
- Убедитесь в стабильности соединения
- Попробуйте разные сети (мобильный интернет, Wi-Fi)
- Проверьте скорость соединения

### 3. Время ожидания
- Подождите 10-15 секунд после отправки формы
- Не нажимайте кнопку несколько раз
- Проверьте, что все поля заполнены корректно

### 4. Альтернативные способы
- Попробуйте зарегистрироваться с другого устройства
- Используйте режим инкогнито
- Попробуйте в разное время суток
