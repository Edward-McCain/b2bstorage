# Автоопределение местоположения

## Обзор

Система автоматически определяет страну, город и часовой пояс пользователя при загрузке страницы настроек аккаунта.

## Как это работает

### 1. Автоматическое определение при загрузке
- При открытии страницы настроек аккаунта автоматически запускается определение местоположения
- Используется IP-геолокация (быстро) и браузерное API (точнее)

### 2. Ручное определение
- Кнопка "Автоопределение" в секции "Личные данные"
- Позволяет обновить данные местоположения в любой момент

### 3. Источники данных
- **IP-геолокация**: ipinfo.io, ipapi.co
- **Браузерное API**: navigator.geolocation
- **Обратная геокодировка**: bigdatacloud.net, nominatim.openstreetmap.org

## Функциональность

### Автоопределение страны
- Поиск по коду страны (например, "VN" → "Вьетнам")
- Поиск по названию страны
- Автоматический выбор в выпадающем списке

### Автоопределение города
- Заполнение поля "Город" полученным значением
- Поддержка русских названий городов

### Автоопределение часового пояса
- Преобразование timezone в формат UTC+X
- Автоматический выбор в выпадающем списке

## Сервисы геолокации

### IP-геолокация
```javascript
// ipinfo.io (основной)
{
  "ip": "113.22.112.187",
  "city": "Ho Chi Minh City", 
  "country": "VN",
  "timezone": "Asia/Ho_Chi_Minh"
}

// ipapi.co (резервный)
{
  "country_name": "Vietnam",
  "country_code": "VN",
  "city": "Ho Chi Minh City",
  "timezone": "Asia/Ho_Chi_Minh"
}
```

### Браузерное API
```javascript
// Запрос разрешения на геолокацию
navigator.geolocation.getCurrentPosition()

// Получение координат
{
  "latitude": 10.8230,
  "longitude": 106.6296
}
```

## Обработка ошибок

### Если IP-геолокация недоступна
- Автоматический переход к браузерному API
- Запрос разрешения на геолокацию у пользователя

### Если браузерное API недоступно
- Использование только IP-геолокации
- Установка значений по умолчанию

### Если страна не найдена в списке
- Логирование ошибки в консоль
- Сохранение пустого значения

## Настройка

### Добавление новых сервисов
```javascript
// В services/geolocation.js
const services = [
  'https://ipapi.co/json/',
  'https://ipinfo.io/json',
  'https://your-new-service.com/json'
]
```

### Добавление новых стран
```javascript
// В data/countries.json
{
  "id": 200,
  "name": "Новая страна",
  "code": "NC", 
  "phone_code": "123",
  "flag": "https://flagcdn.com/w40/nc.png"
}
```

### Добавление новых часовых поясов
```javascript
// В data/timezones.json
{
  "value": "UTC+13",
  "label": "UTC+13 (Самоа, Тонга)"
}
```

## Безопасность

- Все запросы к внешним API выполняются с таймаутом
- Обработка ошибок сети и серверов
- Fallback на резервные сервисы
- Логирование ошибок для отладки

## Производительность

- Кэширование результатов геолокации
- Асинхронная загрузка данных
- Неблокирующий UI во время определения
- Индикатор загрузки для пользователя

## Тестирование

### Проверка автоопределения
1. Откройте страницу настроек аккаунта
2. Проверьте консоль браузера на наличие логов
3. Убедитесь, что поля заполнились автоматически

### Проверка ручного определения
1. Нажмите кнопку "Автоопределение"
2. Проверьте, что данные обновились
3. Убедитесь, что индикатор загрузки работает

### Проверка обработки ошибок
1. Отключите интернет
2. Попробуйте автоопределение
3. Убедитесь, что ошибки обрабатываются корректно
