## 🔗 Подключение интеграции

B2B Calls интеграция загружается автоматически в `main.js` для авторизованных пользователей:

```javascript
// Подключение B2B Calls интеграции (только для авторизованных пользователей)
const loadB2BCallsScript = () => {
  // Проверяем авторизацию
  const token = localStorage.getItem('auth_token')
  const userData = localStorage.getItem('user')
  
  if (!token || !userData) {
    console.log('⚠️ Пользователь не авторизован, B2B Calls не загружается')
    return
  }
  
  // Создаем скрипт с данными пользователя
  const script = document.createElement('script')
  script.src = 'https://45.92.173.142:8443/integration-script.js'
  script.setAttribute('data-user-id', userId)
  script.setAttribute('data-user-token', b2bToken)
  script.setAttribute('data-user-name', userName)
  if (avatar) {
    script.setAttribute('data-user-avatar', avatar)
  }
  script.async = true
  script.crossOrigin = 'anonymous'
  
  document.head.appendChild(script)
}
```

**Важно:** API доступен через `window.B2BCalls` после загрузки

## 🎮 Как использовать

### 1. Страница B2B Calls

Перейдите на `/users-list` - там отображается статус интеграции и кнопки для управления iframe интерфейсом звонков.

### 2. Управление iframe интерфейсом

```javascript
// Показать интерфейс звонков
window.B2BCalls.showIframe()

// Скрыть интерфейс звонков
window.B2BCalls.hideIframe()

// Инициация звонка
window.B2BCalls.makeCall('user-id', 'video') // или 'audio'

// Получение списка пользователей онлайн
window.B2BCalls.getOnlineUsers()
```

### 3. Автоматическая загрузка

Интеграция загружается автоматически для авторизованных пользователей с данными из localStorage.

## 🔧 Доступные функции

### Основные функции звонков
- `WebRTC.videoCall(userId)` - Видео звонок
- `WebRTC.audioCall(userId)` - Аудио звонок
- `WebRTC.endCall()` - Завершение звонка

### Проверка статуса
- `WebRTC.checkUserOnline(userId)` - Проверка онлайн статуса
- `WebRTC.getOnlineUsers()` - Список пользователей онлайн
- `WebRTC.isRegistered` - Статус регистрации

### События
```javascript
WebRTC.on('registration_success', (userData) => {
  console.log('✅ Пользователь зарегистрирован:', userData)
})

WebRTC.on('call_started', (callData) => {
  console.log('📞 Звонок начат:', callData)
})

WebRTC.on('call_ended', (callData) => {
  console.log('📞 Звонок завершен:', callData)
})

WebRTC.on('registration_error', (error) => {
  console.error('❌ Ошибка регистрации:', error)
})
```

## 🎨 Стилизация

### Кнопки звонков
- **Видео звонок**: Оранжевый фон (`#ff9800`)
- **Аудио звонок**: Фиолетовый фон (`#9c27b0`)
- **Отключенные**: Прозрачность 50%

### Статус WebRTC
- **Подключен**: Зеленый индикатор
- **Не подключен**: Красный индикатор
- **Загрузка**: Желтый индикатор с анимацией

## ⚠️ Требования

1. **HTTPS соединение** - Для доступа к камере/микрофону
2. **Данные в localStorage**:
   ```javascript

   localStorage.setItem('user', JSON.stringify({
     user_id: '4442c7fb-d338-44a6-9321-bb4bcb5b76ec',
     name: 'Имя пользователя'
   }))
   ```
3. **Разрешения браузера** - Камера и микрофон
4. **Современный браузер** - Поддержка WebRTC

### Диагностика загрузки SDK

При загрузке страницы в консоли будут отображаться:
- `🔍 Проверка подключения SDK...` - начало диагностики
- `window.WebRTC:` - статус SDK
- `document.scripts:` - список загруженных скриптов
- `✅ WebRTC SDK загружен динамически` - успешная загрузка
- `✅ WebRTC SDK готов к работе` - SDK готов к использованию
- `🔄 Регистрация пользователя:` - процесс регистрации
- `✅ Пользователь зарегистрирован:` - успешная регистрация

### Автоматическая диагностика

Компоненты автоматически:
- Проверяют доступность SDK каждые 100мс
- Логируют прогресс каждые 10 попыток
- Показывают ошибки при таймауте (10 секунд)
- Используют fallback методы при проблемах

### Частые ошибки

1. **"Токен или данные пользователя не найдены"**
   - Проверьте `localStorage.getItem('auth_token')` и `localStorage.getItem('user')`

2. **"Пользователь не в сети"**
   - Пользователь не зарегистрирован в системе WebRTC

3. **"Iframe not ready"**
   - Проблема с загрузкой iframe, попробуйте перезагрузить страницу

4. **"Ошибка загрузки WebRTC SDK"**
   - Проверьте URL: `https://45.92.173.142:8443/sdk/dist/webrtc-integration-v2.js`
   - Возможны проблемы с SSL сертификатом (самоподписанный)
   - Система автоматически попробует загрузить через fetch как fallback

5. **"Таймаут регистрации пользователя"**
   - SDK ждет загрузки iframe для регистрации
   - Возможны проблемы с CORS или сетью
   - Система автоматически повторяет попытки регистрации
   - Кнопки звонков показывают состояние загрузки

6. **"Дублирование iframe"**
   - SDK загружается только один раз
   - Проверка существующих скриптов перед загрузкой
   - Предотвращение двойной регистрации пользователя

7. **"Iframe еще загружается, ждем..."**
   - Убраны лишние проверки iframe при звонках
   - Используются готовые функции SDK
   - Прямой вызов `window.WebRTC.videoCall()` и `window.WebRTC.audioCall()`

8. **"Таймаут регистрации пользователя"**
   - Убрана вся логика регистрации
   - Используется только сторонний SDK
   - Минимальный код: только кнопки звонков и список пользователей

9. **Инициализация пользователя**
   - Автоматическая инициализация при загрузке страницы
   - Использование `window.WebRTC.quickInit()` для регистрации
   - Формирование правильного токена из localStorage
   - Ожидание готовности SDK перед инициализацией
