# Отчет об изменениях в бэкенде - 03.07.2025

## Проблема
Авторизация и регистрация не работали на сервере (ошибка 500), хотя локально работали.

## Решение
Обновлены файлы на сервере для исправления проблем с авторизацией и CORS.

## Измененные файлы

### 1. AuthController.php
**Путь:** `app/Http/Controllers/AuthController.php`
**Что изменили:**
- Обновлен контроллер авторизации и регистрации
- Добавлена поддержка Laravel Sanctum для API токенов
- Исправлена логика создания пользователей с автоматической генерацией `user_id`

### 2. User.php (модель)
**Путь:** `app/Models/User.php`
**Что изменили:**
- Добавлен trait `HasApiTokens` для работы с Sanctum
- Добавлен метод `boot()` для автоматической генерации `user_id` при создании пользователя
- Настроены fillable поля для массового заполнения
- Добавлены кастомные методы для работы с пользователями

### 3. Миграция users таблицы
**Путь:** `database/migrations/2025_07_02_102909_create_users_table.php`
**Что изменили:**
- Обновлена структура таблицы users
- Добавлены все необходимые поля для полноценной работы системы
- Настроены правильные типы данных и ограничения

### 4. API маршруты
**Путь:** `routes/api.php`
**Что изменили:**
- Добавлены маршруты для регистрации и авторизации
- Настроена правильная обработка API запросов

### 5. Конфигурация CORS
**Путь:** `config/cors.php`
**Что изменили:**

## Установленные пакеты
- `laravel/sanctum` - для работы с API токенами

## Выполненные команды на сервере
```bash
# Установка Sanctum
composer require laravel/sanctum

# Публикация конфигурации Sanctum
php artisan vendor:publish --provider="Laravel\Sanctum\SanctumServiceProvider"

# Очистка кэша
php artisan config:clear
php artisan cache:clear
php artisan route:clear
php artisan view:clear

# Перезапуск nginx
systemctl reload nginx
```
