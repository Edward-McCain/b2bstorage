# Исправления для системы оприходований

## Проблемы, которые были исправлены:

### 1. Отсутствие расчета поля `amount` в позициях
- **Проблема**: При создании позиций оприходования не рассчитывалось поле `amount` (количество × цена)
- **Решение**: Добавлен расчет `amount = quantity * price` в методах `store` и `update` контроллера

### 2. Отсутствие расчета общего `total` для оприходования
- **Проблема**: Поле `total` в таблице `receipts` оставалось пустым
- **Решение**: Добавлен расчет общей суммы как сумма всех `amount` позиций + `overhead_costs`

### 3. Отсутствие модели `ReceiptFile`
- **Проблема**: Модель для файлов оприходований не была создана
- **Решение**: Создана модель `ReceiptFile` с правильными связями

### 4. Некорректные поля в методе `update`
- **Проблема**: В методе `update` использовались несуществующие поля `files` и `tasks`
- **Решение**: Удалены некорректные поля из метода обновления

## Измененные файлы:

1. `app/Http/Controllers/ReceiptController.php` - исправлены методы `store` и `update`
2. `app/Models/ReceiptPosition.php` - добавлено поле `amount` в `fillable` и `casts`
3. `app/Models/Receipt.php` - добавлена связь с файлами
4. `app/Models/ReceiptFile.php` - создана новая модель
5. `app/Console/Commands/ClearReceiptsData.php` - создана команда для очистки данных

## Проверка исправлений:

После создания нового оприходования проверьте:

1. **Позиции**: Поле `amount` должно быть равно `quantity * price`
2. **Оприходование**: Поле `total` должно быть равно сумме всех `amount` + `overhead_costs`
3. **Логи**: Не должно быть ошибок в логах Laravel

## Структура таблиц:

### receipts
- `total` - общая сумма оприходования (сумма всех позиций + накладные расходы)

### receipt_positions  
- `amount` - сумма по позиции (quantity * price)

### receipt_files
- Связь с оприходованием через `receipt_id`
