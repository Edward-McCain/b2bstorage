## Инструкция по использованию системы

### 1. Товары

#### Основные функции
- **Просмотр каталога товаров** с возможностью поиска и фильтрации
- **Добавление новых товаров** с указанием названия, описания, категории
- **Редактирование информации** о товарах (название, описание, категория)
- **Загрузка изображений** товаров с предварительным просмотром
- **Управление категориями** товаров

#### Как работать с товарами
1. **Для просмотра товаров**: Перейдите в раздел "Товары" → "Список товаров"
2. **Для добавления товара**: Нажмите "Добавить товар", заполните форму и сохраните
3. **Для редактирования**: Нажмите "Редактировать" рядом с нужным товаром
4. **Для загрузки изображений**: В форме товара нажмите "Выбрать файл" в разделе "Изображения"

#### Фильтрация и поиск
- Используйте поле поиска для быстрого нахождения товаров по названию
- Фильтруйте по категориям для просмотра товаров определенной группы
- Сортируйте товары по дате создания, названию или категории

### 2. Оприходования

#### Основные функции
- **Создание оприходований** с указанием поставщика, даты и товаров
- **Просмотр списка оприходований** с детальной информацией
- **Редактирование оприходований** в статусе "Черновик"
- **Подтверждение оприходований** для перевода в статус "Подтверждено"
- **Загрузка документов** (накладные, счета-фактуры)

#### Процесс работы с оприходованиями
1. **Создание**: Перейдите в "Оприходования" → "Создать оприходование"
2. **Заполнение данных**: Укажите поставщика, дату, товары и количества
3. **Добавление документов**: Загрузите связанные документы
4. **Подтверждение**: Нажмите "Подтвердить" для завершения процесса
5. **Просмотр**: Используйте фильтры для поиска нужных оприходований

#### Статусы оприходований
- **Черновик**: Можно редактировать и удалять
- **Подтверждено**: Заблокировано для редактирования
- **Отменено**: Операция отменена

### 3. Списания

#### Основные функции
- **Создание списаний** товаров с указанием причины и количества
- **Просмотр истории списаний** с детализацией
- **Подтверждение списаний** уполномоченными лицами
- **Загрузка документов** обоснования списания

#### Процесс списания
1. **Создание**: Перейдите в "Списания" → "Создать списание"
2. **Выбор товаров**: Укажите товары и количество для списания
3. **Обоснование**: Укажите причину списания (брак, истечение срока и т.д.)
4. **Документы**: Загрузите документы, обосновывающие списание
5. **Подтверждение**: Получите подтверждение от ответственного лица

#### Типы списаний
- **Брак**: Товары, не соответствующие качеству
- **Истечение срока**: Просроченные товары
- **Порча**: Поврежденные товары
- **Другое**: Иные причины списания

### 4. Инвентаризации

#### Основные функции
- **Создание инвентаризаций** по складам или товарным группам
- **Проведение инвентаризации** с подсчетом фактических остатков
- **Сравнение плановых и фактических остатков**
- **Автоматическое создание корректировок** при расхождениях
- **Формирование отчетов** по результатам инвентаризации

#### Процесс проведения инвентаризации
1. **Планирование**: Создайте инвентаризацию с указанием склада и товаров
2. **Подсчет**: Внесите фактические остатки товаров
3. **Сравнение**: Система автоматически сравнит плановые и фактические остатки
4. **Корректировка**: При расхождениях создаются корректировочные документы
5. **Отчет**: Получите итоговый отчет по инвентаризации

#### Типы инвентаризаций
- **Полная**: По всем товарам склада
- **Выборочная**: По определенным товарным группам
- **Внеплановая**: По требованию руководства

### 5. Перемещения

#### Основные функции
- **Создание перемещений** товаров между складами
- **Просмотр истории перемещений** с детализацией
- **Автоматическое обновление остатков** при перемещении
- **Отслеживание статуса** перемещений

#### Процесс перемещения
1. **Создание**: Перейдите в "Перемещения" → "Создать перемещение"
2. **Выбор складов**: Укажите склад-отправитель и склад-получатель
3. **Выбор товаров**: Укажите товары и количество для перемещения
4. **Подтверждение**: Система автоматически выполнит перемещение
5. **Контроль**: Просмотрите обновленные остатки на складах

#### Фильтрация перемещений
- По складам (откуда/куда)
- По дате перемещения
- По статусу операции

### 6. Остатки

#### Основные функции
- **Просмотр текущих остатков** по всем складам
- **Детализация остатков** по товарам и складам
- **История движения** товаров
- **Отчеты по остаткам** в различных разрезах

#### Работа с остатками
1. **Общий обзор**: Перейдите в "Остатки" для просмотра всех остатков
2. **Детализация**: Нажмите на товар для просмотра детальной информации
3. **Фильтрация**: Используйте фильтры по складам, категориям товаров
4. **Отчеты**: Сформируйте отчеты по остаткам в нужном формате

#### Типы отчетов
- **Остатки по складам**: Текущие остатки на каждом складе
- **Остатки по товарам**: Остатки конкретного товара на всех складах
- **Движение товаров**: История поступлений и списаний
- **Критические остатки**: Товары с низкими остатками

### 7. Склады

#### Основные функции
- **Создание и управление складами**
- **Настройка параметров** складов (адрес, ответственные лица)
- **Просмотр информации** о складах
- **Управление зонами** хранения на складах

#### Управление складами
1. **Создание склада**: Перейдите в "Склады" → "Добавить склад"
2. **Заполнение данных**: Укажите название, адрес, ответственных лиц
3. **Настройка зон**: Создайте зоны хранения для организации склада
4. **Контроль**: Регулярно проверяйте информацию о складах

#### Информация о складе
- **Основные данные**: Название, адрес, контакты
- **Ответственные лица**: Кто отвечает за склад
- **Зоны хранения**: Организация пространства склада
- **Статистика**: Количество товаров, общая стоимость остатков
