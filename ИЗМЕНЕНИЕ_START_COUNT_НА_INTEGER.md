# Изменение типа поля start_count с DECIMAL на INTEGER

## Обзор изменений

Поле `start_count` в таблице `products_sklad` изменяется с `NUMERIC(15,3)` на `INTEGER` для упрощения работы с начальными остатками товаров.

## 🔄 Шаги для применения изменений:

### 1. 🗄️ Изменение базы данных

**Вариант A: Прямой SQL запрос**
```sql
-- Выполните содержимое файла change_start_count_to_integer.sql
```

**Вариант B: Через Laravel миграцию**
```bash
cd b2b-project/backend
php artisan migrate
```

### 2. 🔧 Обновления уже применены в коде:

#### Backend:
- ✅ **ProductSklad.php**: Добавлен cast `'start_count' => 'integer'`
- ✅ **ProductController.php**: Валидация изменена с `'numeric'` на `'integer'`
- ✅ **Миграция**: Создана для изменения типа поля

#### Frontend:
- ✅ **ProductCreatePage.vue**: Поле изменено на `step="1"` вместо `step="0.001"`
- ✅ **ProductsPage.vue**: Поле импорта изменено на `step="1"` + `parseInt()` вместо `parseFloat()`

## 📋 Структура после изменений:

### База данных:
```sql
start_count | INTEGER | NOT NULL | DEFAULT 0 | 'Начальный остаток товара (целое число)'
```

### Валидация (Backend):
```php
'start_count' => 'required|integer|min:0'
```

### Приведение типов (Backend):
```php
protected $casts = [
    'start_count' => 'integer',
    // ...
];
```

### Поля ввода (Frontend):
```html
<input v-model.number="product.start_count" type="number" step="1" min="0" />
```

## 🎯 Преимущества изменения:

1. **Простота**: Товары имеют целые количества (штуки, упаковки)
2. **Производительность**: INTEGER быстрее DECIMAL для вычислений
3. **Точность**: Избежание проблем с плавающей точкой
4. **UX**: Более интуитивно для пользователей

## ✅ Результат:

После применения изменений:
- Начальные остатки товаров вводятся только как целые числа
- Валидация корректно проверяет integer значения
- Поля ввода настроены на работу с целыми числами
- База данных оптимизирована для работы с integer значениями

## 🚨 Важно:

Если в базе данных уже есть данные с дробными частями (например, 10.5), они будут автоматически обрезаны до целых (10) при выполнении SQL запроса `USING start_count::INTEGER`.
