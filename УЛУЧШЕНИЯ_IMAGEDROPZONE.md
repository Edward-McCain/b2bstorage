# Улучшения компонента ImageDropzone.vue

## Проблемы, которые были исправлены:

### 1. Отсутствие индикации загрузки ❌ → ✅ ИСПРАВЛЕНО
**Проблема:** При выборе изображения не было визуальной индикации процесса загрузки.

**Решение:**
- Добавлен массив `uploadingFiles` для отслеживания загружающихся файлов
- Создается плитка с превью изображения и спиннером `Loader2` во время загрузки
- Показывается процент загрузки и прогресс-бар
- Добавлена функция `createImagePreview()` для создания превью загружающегося файла

### 2. Неправильное отображение изображений ❌ → ✅ ИСПРАВЛЕНО
**Проблема:** Изображения показывались как "data:..." вместо корректных URL, отображалась "Ошибка загрузки".

**Решение:**
- Исправлена функция `imageSrc()` для правильного формирования путей
- Убирается ведущий слеш из пути
- Корректно формируется полный URL с доменом
- Поддержка различных форматов путей (с `/storage/` и без)

### 3. Черный overlay на изображениях ❌ → ✅ ИСПРАВЛЕНО
**Проблема:** Overlay был полностью черным (непрозрачным).

**Решение:**
- Изменена прозрачность overlay с `bg-opacity-100` на `bg-opacity-20`
- Удалена кнопка просмотра изображения
- Оставлена только кнопка удаления

### 4. Улучшения UX/UI:
- ✅ Превью загружающегося изображения с полупрозрачным overlay
- ✅ Спиннер `Loader2` с анимацией вращения
- ✅ Процент загрузки в реальном времени
- ✅ Прогресс-бар внизу плитки
- ✅ Показ имени файла (сокращенного если длинное)
- ✅ Плитки загрузки показываются даже когда нет загруженных изображений

### Исправленная функция imageSrc:
```javascript
function imageSrc(img) {
  // Убираем ведущий слеш если есть
  let cleanPath = imagePath.startsWith('/') ? imagePath.substring(1) : imagePath
  
  // Формируем полный URL
  if (cleanPath.startsWith('storage/')) {
    fullUrl = `${window.location.origin}/${cleanPath}`
  } else {
    fullUrl = `${window.location.origin}/storage/${cleanPath}`
  }
  
  return fullUrl
}
```

### Функция создания превью:
```javascript
function createImagePreview(file) {
  return new Promise((resolve) => {
    if (file.type.startsWith('image/')) {
      const reader = new FileReader()
      reader.onload = (e) => resolve(e.target.result)
      reader.onerror = () => resolve(null)
      reader.readAsDataURL(file)
    } else {
      resolve(null)
    }
  })
}
```
